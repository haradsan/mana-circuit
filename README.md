# ✦ マナサーキット ✦

カードゲーム × ボードゲームの対戦ゲーム（vs CPU／⚔三つ巴／🎮2人対戦）。
セガサターンの名作『カルドセプト』へのオマージュ作品です。

## 遊び方

**`index.html` をブラウザで開くだけ**（インストール・通信不要、オフラインで動きます）。

### ルール概要
- 🎲 ダイスを振って周回ボードを移動
- 空き地に止まったら手札のクリーチャーを召喚して土地を確保
- 敵の土地では「通行料を支払う」か「クリーチャーで侵略バトル」
- 同じ属性（🔥火・🌳木・⛰️地・💧水）の土地を集めると**連鎖**で通行料が倍増
- 自分の土地はレベルアップで価値と通行料アップ。**クリーチャーの交代**も可能
- 隣接する自軍領地で防衛クリーチャーが強くなる（**土地の援護** ST+10〜最大+40）
- ⛩️関門を規定数（多くのステージで3つ）そろえて🏰城を**通過または停止**すると周回ボーナス＝魔力＋自軍全回復（劣勢時は魔力1.5倍の「逆転の風」）
- 🏰城に**ぴったり停止（またはリコール）**すると、周回に関係なく**領地コントロール**＝全自領を対象に1回行動できる
- 1ターンの能動行動は1回。停止マスで行動しなかったターンは、通過した自領について
  **🏇侵攻・🔄交代・⬆レベルアップ**のどれか1つを行える（②通過アクション。出発マスは対象外）。
  自分の土地に到達したときは、レベルアップ・交代に加えて駐留クリーチャーの**🏇侵攻**も選べる
- 選択中でないときに盤面のマスをクリックすると、**駐留クリーチャーの能力・実効防衛値・通行料**などの情報を確認できる
- 分かれ道では**盤面のマスが光って矢印が出る**。行きたいマスを直接タップして進む方向を決める（v31。ダイアログは出ない）
- 🤝**絆**（v31）: 一部のクリーチャーには**相方**がいて、**相方が自分の領地に駐留している間だけ**本来の力を出す。
  戦闘の強化にとどまらず、**毎ターンの収入・全体回復・ダイスの出目+1・侵攻の射程・通行料**まで変わる。
  カードの🤝タグは成立していると**金色に灯る**
- **ステージごとの目標資産に達して🏰城に凱旋したら勝利！**（目標到達で⚑凱旋リーチ表示）。
  **魔力が尽きても敗北にはならない**——払いきれないときは持てる全てを渡して城へ帰還し、初期魔力で再スタート（v18）。
  勝つには相手を締め上げるだけでは足りず、**自分が凱旋するしかない**
- **⏱ 決着モード（v18）**: タイトルの「⏱ 決着」で**短期戦／標準／長期戦／大戦**を選べる
  （目標資産とラウンド上限が変動。じっくり長期戦も、サクッと短期決戦も）
- プレイヤーの情報は**画面上部に3名分を圧縮して常時表示**、手札と🎲ダイスは**画面下段**——
  どれも盤面には重ねていないので**盤面が隠れない**（v27）。
  自分の番でダイスを振る前は🏳投了でゲームを中断できる
- ステージは選んだあとに**出陣確認**が入る。相手・マス数・目標資産を見てから「選び直す」こともできる（v28）

### ステージ（全16面）
クリアすると次のステージが解放される（進行はブラウザに自動保存）。
**盤面の形とマス数（16〜56）が全ステージで異なる**: 小さな環、細長い高地、
橋や尾根の近道（分岐）、2つの環が城で交差する「八の字」、縦横の谷道が交わる「十字路」、
星型の「四つ辻」、魔王城への地獄回廊、三方から城へ道が流れ込む「円卓の三叉界」（v18・三つ巴向き）など。
**⏳第二弾の大型4面（v20・S13〜S16）**: 隊商路が横切る46マスの「隊商の大草原」、外環と内環が
一方通行の歯車道で噛み合う56マスの「時計仕掛けの大環」、そしてボス面——👑精霊王4体を従える巫女の
「五王の間」（56マス・玉座4つ全て必須）と、時空王アイオーンが写し身と待つ最終決戦「時流の玉座」（51マス）。
ボスは精霊王を**固定エース**としてデッキに確定投入してくる。
ワープ🌀・マグマ🌋・疾風💨に加えて**🎰運命マス**（ルーレット＝大当り+300G〜はずれ-100G）と
**⛲泉マス**（自軍全回復+60G）が波乱を呼ぶ（v18）。ステージごとに**背景と回路の色**も変わり、
通行料レート・CPUの性格・得意属性も異なる。**移動は進行方向へ（v24）**——コマは今の進行方向を保って進み、
**逆走はできない**。分かれ道・交差点では背後以外の行く手を選べる。逆方向へ進めるのは
**🔄時流逆転**（スペル。相手から強制的に反転させられることもある）と🎰運命マスの**🌀時空の渦**（イベント）だけ。
盤面の方向制限は**➡一方通行マス**（S10地獄回廊・S14歯車道。盤面に大矢印で表示）で、
スペル「🚧バリケード」で一時的な通行止めも作れる。

### バトル
- **属性相性**: 🔥火 → 🌳木 → ⛰️地 → 💧水 → 🔥火（左が右に強い、ST+10。＝水＞火＞木＞地＞水）
- 低確率で**💫会心の一撃**（ダメージ1.5倍）が発生。格上にも一発逆転の目がある
- **戦闘後は残りHPのまま駐留**し傷が残る（周回で全回復）
- 特殊能力: **先制**／**貫通**／**強襲**（侵略時ST+20）／**守護**（防衛時HP+20）／**豪運**（会心率25%）／
  **捕縛**（撃退した侵略者を1ターン拘束）／**不動**（侵略・侵攻に出せない防御専用・高HP）／
  **護法**（敵の対象指定スペルの対象にならない）／**連撃**（バトルで続けて2回攻撃）／
  **物理無効**（物理攻撃が効かない）／**物理反射**（物理攻撃をそっくり跳ね返す）／**魔法攻撃**（攻撃が魔法＝無効・反射を貫く）／
  **模倣**（バトル時、相手の基本ST・HP・能力をそっくり写し取って戦う・v17）
- **🏞 領地に働きかける希少特性（v25）**: バトルの結果が土地そのものを変える一群。
  **築城**（防衛に勝つたびその領地がLv+1・最大5）／**焦土**（防衛時HP+30だが、その土地でバトルが起きるたびLv-1）／
  **破城**（侵攻で攻め込むとき、バトル前に相手の領地をLv-1＝土地の加護ごと城壁を砕く）／
  **遁走**（敗れても消滅せず、空いている領地へHP全快で逃げ延びて自領にする）／
  **応援**（隣接する自領のクリーチャーに武具を貸すように ST+15/HP+15・2体まで重複）／
  **魔力強奪**（与えたダメージと同量の魔力を奪う）／**二形**（クリーチャーとしても武具としても使える）

- **盤面（v31で刷新）**: マス目の**形**・マス間の**余白**・道の**太さ**がステージごとに違う
  （🌿草原=木の葉／🌋火山峠=六角の柱状節理／🌊水都=円／💰市場=面取りの宝石／⚔️闘技場=詰まった円／⚙️機構都市=歯車…）。
  **特別マス（🏰城・⛩️関門・💎魔力・🎰運命・🌋マグマ）の形は全ステージ共通**なので、形を見ればマスの種類が分かる。
  盤面の背景にはステージの紋章と銘板が薄く敷かれる。
  → **[盤面プレビュー](preview-board.html)** で全16面の見た目を一覧できる
- **駒（v31で刷新）**: マントを羽織った術者の立像。手番の駒は**足元の魔法陣が回り、頭上に▼**が出る。
  同じマスに重なっても全員が見えるように自動で並び、盤面の端でも切れない
  （マス目の情報が駒の下に隠れることはあるが、🔍マス情報でいつでも確認できる）

### 画面レイアウト（v27／v28）
盤面の見やすさを最優先に、**盤面の上に固定表示を重ねない**構成へ作り替えた（v27）。
v28では**片手で持ったスマホでの押しやすさ**を基準にボタンの置き場所を組み直した。

- **👥 情報窓（画面上部・3名分）**: 順位（🥇🥈🥉）・魔力・総資産バー・連鎖・関門・周回・山札を
  1人3行に圧縮して横並びで固定表示（2人対戦なら2列で広く使う）。**クリックすると所有地の一覧まで見られる詳細**が開く
- **🎲 ダイスは画面右下の丸いボタン**（直前の出目もここに表示）。盤面中央から追い出したので、
  中央のマス（城・十字路など）が隠れない。PCでは**Space / Enter**でも振れる。
  **🃏手札の開閉はそのダイスの真上**（v28）＝手札を畳んで盤面を見て、また戻す、が親指だけで完結する
- **🗺 マップ確認モード**: 情報窓・ログ・手札を一時的に片付けて**マス目の表示を最優先**にし、盤面を画面いっぱいへ拡大。
  もう一度押すと元の倍率に戻る（**Mキー**でも切替／自分のダイス待ちになると自動で解除）
- **「見るための窓」は1列に**（v28）: **👥情報窓／📜ログ（Lキー）／🗺マップ／🗑捨札**を上部右の同じ列にまとめた。
  隠すぶん盤面が自動で広がり、**選んだ状態は次回も保たれる**
- **ヘッダーは常に横一行**（v28）: 拡大縮小（－ 100% ＋ ⛶）・🔊・🎵・❓が折り返さない。
  ズーム枠は**対戦中だけ**表示（タイトルでは盤面が無いので出さない）＝狭い画面でも盤面の高さを削らない
- **📜 ログ**は広い画面では盤面の右（正方形の盤面では必ず余る余白）に縦長で並ぶ。狭い画面では既定で非表示
  （🔔ポップアップ通知があるので閉じていても重要な出来事は分かる）
- **🥇 現状順位**は**総資産順**（同額は同順位）。ラウンド上限での資産勝負もこの順位のとおりに決まる。
  情報窓を隠していても上部の対戦情報に首位が出る
- **🔔 ポップアップ通知**: **スペルの効果・特性の発動・機能停止（スペル封じ／足止め／無力化など）・
  通行料・魔力不足**といった「影響のあった出来事」を、📜ログと同じ文言で画面上部に短く表示してすぐ消す。
  **ログを閉じたまま遊んでも見落とさない**ための表示で、盤面やダイアログの操作は一切邪魔しない

### モード・その他
- **⚔ 三つ巴（v18）**: あなた＋ステージの主＋**ランダムな乱入キャラ**の3人戦。**全ステージ**から選べ、
  勝てばカード**7枚＝1対1より+2枚**（進行度は変化なし・v22）。相手を選ぶスペル（ドレイン・フリーズ等）は**対象を選択**して撃つ
- **🎭 対戦相手キャラ（v18）**: 全12人の相手に**顔絵・肩書き・セリフ**。対戦前の口上、
  侵略・バトル勝敗・通行料・周回・再起——場面ごとに吹き出しで語りかけてくる
- **🎮 2人対戦（ホットシート）**: 同じ端末を交互に操作する人間同士の対戦。プレイヤーを2人選び、
  **全ステージ**から盤面を選べる。各自の使用中デッキで戦い、手番交代時は手札が伏せられる（報酬・進行度は変化なし）
- **🎁 シールド戦（v21）**: その場で**第一弾5＋第二弾5パック（計50枚）を開封**し、出たカードだけで
  30枚デッキを組んで1戦する特別モード。**全ステージ**から選べ、開封プールは**使い捨て**（コレクションに入らない）＝
  コレクションが浅いプロファイルでも対等に遊べる。勝てば通常の勝利報酬パック5枚（進行度は変化なし）
- **🎪 ウィークリールール**: 毎週月曜に切り替わる特殊ルール（通行料2倍・初期手札レジェンド保証・出目4〜6のみ 等の全7種）。
  タイトルの「🎪 週替り」でON/OFF。ONで**正規対戦・⚔三つ巴**に勝つと**ボーナスカード+2枚**（トレーニングには適用されない・v22で三つ巴も対象に）
- **🎵 BGM（v28でファミコン風に）**: **既定はON**。ヘッダーの🎵でON/OFF（🔊はその隣＝効果音のON/OFF）。
  効果音と同じくWebAudioで自動生成（オフライン動作・外部ファイル不要）。
  ブラウザの決まりで音は**最初のタップから**流れ始める＝オープニングの「✦ クリック / タップ で始める ✦」が再生の合図になる。
  矩形波2ch＋三角波ベース＋ノイズドラムという**ファミコン（2A03）と同じ編成**を模したチップチューン。
  **場面ごとに6曲**を自動で切り替える（v28.3）:
  | 場面 | 曲 |
  |---|---|
  | オープニング・ステージ選択・アルバム・デッキ構築 | ゆったりした行進曲（ハ長調・112BPM） |
  | 対戦中 | 走る8ビート（イ短調・152BPM） |
  | **ボス戦**（S15五王の間／S16時流の玉座） | 追い立てる速い曲（ニ短調ハーモニック・168BPM） |
  | **勝利** | ファンファーレ（ハ長調・132BPM） |
  | **敗北** | 下降する静かな曲（ドラム無し・84BPM） |
  | **カードパック開封** | 高音で跳ねるきらめき（144BPM。閉じると前の曲へ戻る） |
  - **スマホでも鳴る**: 自動再生制限に合わせて最初のタップで開始し、鳴り出すまでタップのたびに再試行。
    **iPhoneはサイレントスイッチ（マナーモード）がONだとWebAudioが無音になる**ため、
    無音の音源を裏で再生してセッションを「メディア再生」に上げる対策を入れてある（それでも鳴らないときは案内が出る）
- **⚔ 出陣確認（v28）**: ステージを選ぶと、開戦前に**相手の顔・盤面のマス数・目標資産・関門数・適用中のルール**を
  まとめた確認画面が出る。「**← ステージを選び直す**」で一覧に戻れる（v27まではタップした瞬間に開戦していた）。
  その次の「⚔ 対戦相手（口上）」画面からも「**← ステージ選択へ戻る**」で引き返せる
  （🎁シールド戦だけは、開封したプールが消えてしまうためここでは戻れない）
- **📱 スマホ最適化（v17／v28）**: 手札は**◀▶ボタンで1枚ずつ送れる**（横スワイプ不要＝Androidの「戻る」ジェスチャーと衝突してゲームが終了する事故を防ぐ。手札カードも縮小表示）。
  ヘッダーの**「⛶ 全体」ボタン**で盤面全体が画面に収まる倍率へワンタップ調整（対戦開始時も自動フィット）。
